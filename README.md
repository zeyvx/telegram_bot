# Telegram-бот службы поддержки

Telegram-бот для приёма и обработки обращений пользователей в службу поддержки. Пользователь регистрируется по номеру телефона, создаёт заявку с выбором категории и описанием проблемы, может приложить документ или фото, а также просматривать историю своих обращений.

## Стек технологий

- **Python 3**
- **[aiogram](https://docs.aiogram.dev/)** — асинхронный фреймворк для Telegram Bot API
- **aiosqlite** — асинхронная работа с SQLite
- **python-dotenv** — загрузка переменных окружения из `.env`

## Функциональность

- 📱 Регистрация пользователя по номеру телефона (через кнопку "Отправить контакт")
- 📋 Подача заявки:
  - выбор категории проблемы (техническая, оплата, доставка, заказ, другое)
  - текстовое описание проблемы
  - прикрепление документа или фото (или пропуск этого шага)
- 📂 Просмотр своих заявок с постраничной навигацией
- ☎️ Быстрая связь с оператором
- 🔒 Базовая защита от некорректного ввода на каждом шаге сценария (нетекстовые сообщения, дубликаты регистрации и т.д.)

## Установка и запуск

1. **Клонируйте репозиторий:**

   ```bash
   git clone https://github.com/zeyvx/telegram_support_bot.git
   cd telegram_support_bot
   ```

2. **Установите зависимости:**

   ```bash
   pip install -r requirements.txt
   ```

3. **Создайте файл `.env`** в корне проекта на основе `.env.example` и укажите токен бота, полученный от [@BotFather](https://t.me/BotFather):

   ```
   BOT_TOKEN=ваш_токен_бота
   OPERATOR_PHONE=номер_оператора
   ```

4. **Запустите бота:**

   ```bash
   python main.py
   ```

При первом запуске автоматически создаётся файл базы данных `database.db` со всеми необходимыми таблицами.

## Структура проекта

```
telegram_bot/
├── main.py                    # Точка входа, запуск бота
├── requirements.txt            # Зависимости проекта
├── .env                        # Переменные окружения (не хранится в репозитории)
└── handlers/
    ├── routers.py               # Хендлеры сообщений и callback-запросов
    ├── keyboards.py              # Клавиатуры (inline и reply)
    ├── database.py                # Работа с базой данных (SQLite)
    └── Forms/
        └── request_send.py          # FSM-состояния для сценария подачи заявки
```
